# Realize Beauty

## Vision

美容サロンの業務をシンプルにし、本来の接客・施術へ集中できる環境を提供する。

---

## Product Principles

Realize Beautyは将来的に複数店舗・複数スタッフで利用できるSaaSを目指します。

そのためMVP段階から以下を設計へ取り入れます。

- salon_idによるマルチテナント設計
- Roleによる権限制御
- SoftDelete
- REST API
- API First

---

## Mission

小規模美容サロンでも導入しやすい価格と使いやすさで、
顧客管理・カルテ・AI活用を提供する。
