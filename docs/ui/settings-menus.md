# Settings - Menus

## 概要

施術メニューを管理する（一覧・登録・編集・削除・並び順・有効/無効）。

設定画面（[settings.md](settings.md)）の「メニュー管理」カードから遷移する。

---

## Route

`/settings/menus`

---

## Components

### Menu Table

* 列: 並び順操作（↑↓）／メニュー名／価格（¥表示）／所要時間（分）／有効（Tag: 有効=Primary・無効=グレー）／操作（編集・削除）
* display_order 昇順で表示する
* 無効（is_active=false）の行は淡色表示する

### New Menu Button

* ＋ 新規登録（ダイアログを開く）

### MenuFormDialog（新規・編集共通）

| 項目 | UI | 備考 |
|------|----|------|
| メニュー名 | InputText | 必須・最大100文字 |
| 価格（税込・円） | InputNumber | 必須・0〜9,999,999 |
| 所要時間（分） | InputNumber | 必須・5〜480 |
| 有効 | ToggleSwitch | 既定 true |

* 並び順はダイアログでは編集せず、一覧の ↑↓ ボタンで入れ替える（入れ替え時に対象2件の display_order を PUT で更新）
* 新規登録時は display_order を送信しない（サーバが同一サロン内の max(display_order)+1 を採番する）

### 削除確認ダイアログ

* 「削除しても過去の予約履歴には残ります」の注記を表示する

---

## API

* GET /api/v1/menus（is_active フィルタは付けず全件表示）
* POST /api/v1/menus
* PUT /api/v1/menus/{id}
* DELETE /api/v1/menus/{id}

---

## Actions

* 新規登録
* 編集
* 削除（Soft Delete）
* 並び順の変更（↑↓）
* 有効/無効の切り替え

---

## 空状態

* メニュー0件時は空状態メッセージと「＋ 新規登録」ボタンを表示する

---

## エラー時挙動

* 422 はダイアログを閉じず、フィールド単位でエラーメッセージを表示する
* その他のエラーは Toast で通知する
