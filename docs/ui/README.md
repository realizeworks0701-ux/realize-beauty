# UI設計

## 目的

Realize Beauty のフロントエンド画面設計を管理する。

本ディレクトリでは以下を管理する。

* 画面一覧
* 画面遷移
* 共通レイアウト
* デザインルール
* 各画面のUI設計

## 基本方針

* Vue 3 + TypeScript
* PrimeVueを採用
* モバイルよりPC利用を優先
* シンプルで迷わないUI
* 美容サロン向けの柔らかいデザイン
* MVPでは必要最低限の機能を優先する

## 共通ルール

* CRUD画面は一覧→詳細→編集の流れを統一する
* フォームレイアウトは全画面共通化する
* ボタン配置・カラーを統一する
* APIとの責務を明確に分離する
