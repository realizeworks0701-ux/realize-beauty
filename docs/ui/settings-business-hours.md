# Settings - Business Hours

## 概要

曜日別の営業時間・定休日を設定する。

設定画面（[settings.md](settings.md)）の「営業時間設定」カードから遷移する。

営業時間はカレンダーの時間外グレーアウト表示と、フェーズ2の顧客向けWeb予約の制約に使用する。
サロン側の手動予約はブロックしない（[ADR-023](../decisions/ADR-023-reservation-core.md)）。

---

## Route

`/settings/business-hours`

---

## Components

### 曜日別行エディタ（7行固定・日曜〜土曜）

| 項目 | UI | 備考 |
|------|----|------|
| 曜日 | ラベル | 日〜土 |
| 定休日 | ToggleSwitch | is_closed |
| 開店時刻 | 時刻入力（HH:MM） | 定休日ONの行は無効化（値は保持） |
| 閉店時刻 | 時刻入力（HH:MM） | 同上。開店時刻より後 |

* 初期表示は GET /api/v1/business-hours の7件（未設定曜日は 09:00〜19:00 のデフォルトが返る）
* 保存は7件一括（PUT）。行ごとの保存はしない

### 保存ボタン

* 一括保存（変更がない場合は無効化）

---

## API

* GET /api/v1/business-hours
* PUT /api/v1/business-hours

---

## Actions

* 定休日の切り替え
* 開店・閉店時刻の変更
* 一括保存

---

## エラー時挙動

* 422（閉店時刻が開店時刻以前など）は該当行にフィールド単位でエラーメッセージを表示する
* 保存成功は Toast で通知する
* 取得失敗時はエラーメッセージ＋再読み込みボタンを表示する
